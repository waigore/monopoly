# Game specs

## Quick start

Document how the property-trading game works: board, streets, railroads, utilities, buying and rent, houses and hotels, Chance and Community Chest, jail, auctions, trading, and bankruptcy.

Keep rules independent of any user interface. Link related [UI](../ui/), [module](../module/), and [test](../test/) specs instead of repeating them. House rules wait for an explicit option; see [AGENTS.md](../../AGENTS.md).
