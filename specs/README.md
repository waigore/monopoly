# Specs

## Quick start

Write design and contract notes as Markdown under this tree. Follow the Markdown conventions in [AGENTS.md](../AGENTS.md). Put each document in the folder that matches its subject.

| Folder | Use for |
| --- | --- |
| [game/](game/) | Game design: rules, board, cards, economy |
| [ui/](ui/) | UI and UX: screens, flows, interaction |
| [tech/](tech/) | Tech stack and non-functional requirements |
| [module/](module/) | Modules, contracts, and integration |
| [test/](test/) | Testing tools and how to run tests |
