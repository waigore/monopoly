# Tech specs

## Quick start

Document the tech stack and non-functional requirements: platforms, performance, persistence, accessibility, security, and similar constraints.

Do not choose a language, framework, or engine in this folder until maintainers agree; see [AGENTS.md](../../AGENTS.md). Link [module](../module/) contracts and [test](../test/) tooling instead of duplicating them.
